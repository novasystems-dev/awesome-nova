## Official Resources

- [Nova Core Repository](https://github.com/novasystems-dev/nova) — Core compiler and standard library.
- [Orbit](https://github.com/novasystems-dev/orbit) — Official package manager and build system.
- [Nova-Analyzer](https://github.com/novasystems-dev/nova-analyzer) — Official Language Server Protocol engine.
- [The Nova Book](https://github.com/novasystems-dev/book) — The official textbook for learning Nova.
- [Nova RFCs](https://github.com/novasystems-dev/rfcs) — Language evolution and feature proposals.
- [Nova-Runtime](https://github.com/novasystems-dev/nova-runtime) — Perceus region allocator & FFI engine.
- [Playground](https://github.com/novasystems-dev/playground) — Interactive in-browser compiler sandbox.

## Development Tools

- `orbit`: Ultra-fast package manager and capability auditor.
- `nova-fmt`: Official source code formatter.
- `nova-lint`: Static analysis and style enforcement.
- `nova-doc`: Markdown API documentation generator.
- `nova-repl`: Real-time interactive evaluation pipeline.
